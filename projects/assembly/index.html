How this works, and why it works everywhere

The headline above is not an image, a font file, or a canvas fillText call. It is a real <h1>, laid out and typeset by your browser in your own fonts. It was rasterised once into a texture; every non-transparent pixel became a particle with a target position and a colour sampled from that pixel. What you see is those particles under spring forces on the GPU.

The html-in-canvas proposal adds drawElementImage(), which does that rasterisation natively — and, crucially, can redo it every frame, so the texture tracks a live, changing page. That is the part that needs chrome://flags/#enable-experimental-web-platform-features.

But this effect only ever needs one snapshot. Once the particle targets exist, the DOM has done its job. And a single snapshot has been available in every browser for years, via an SVG <foreignObject> drawn to a canvas. So this page takes the native path when the flag is on and the universal path when it is not, and the result is pixel-identical. The status line below the headline tells you which one you got.

That is the useful distinction, and it is not the one the demos make. Ask whether your effect needs the DOM live or merely needs it once. Live means you are shipping a flagged feature nobody has enabled. Once means you can ship today.

The part that is genuinely still real

Try to select the headline. Use find-in-page for the word nothing. It is there, because the element was never removed — only faded to opacity: 0, which keeps it in the accessibility tree and in the text layer. A screen reader reads a heading, not a canvas.

Honest caveat, and it is the exact hazard worth naming: because the glyphs are painted by the GPU and the element itself is transparent, your selection highlight lands on invisible text. That is the tension in all of this — the moment you move pixels away from where the browser put them, input and visuals stop agreeing. Here nothing moves until you push it, so it mostly holds. Reduced motion is honoured: the particles settle instantly and the cursor forces are off.
